# 위반 2 — "게시자 콘텐츠가 없는 화면에 Google 게재 광고"

애드센스 반려 통지에는 위반이 **두 건** 들어 있습니다. 이 문서는 두 번째
건입니다. 첫 번째("가치가 별로 없는 콘텐츠")는
[`ADSENSE_FIX.md`](ADSENSE_FIX.md) 를 보세요.

> 다음과 같은 화면에는 Google 게재 광고가 허용되지 않습니다.
> - 콘텐츠가 없거나 가치가 낮은 콘텐츠를 포함한 화면
> - 아직 준비 중인 화면
> - 알림, 이동 또는 기타 행동 목적으로 사용되는 화면

**이건 글의 문제가 아니라 광고가 어디에 붙어 있느냐의 문제입니다.** 그래서
이 저장소의 파이썬 코드로는 고칠 수 없습니다. Blogger 관리 화면에서
직접 하셔야 합니다.

---

## 왜 걸렸는가

Blogger는 글 페이지 말고도 여러 종류의 화면을 자동으로 만듭니다.

| 화면 | 주소 예시 | 성격 |
|---|---|---|
| 라벨(카테고리) 목록 | `/search/label/재테크` | **이동 목적** — 목록만 있음 |
| 검색 결과 | `/search?q=...` | **이동 목적** |
| 날짜별 보관함 | `/2026/08/` | **이동 목적** |
| 404 오류 | 없는 주소 | **알림 목적** |
| 빈 고정 페이지 | 만들다 만 페이지 | **준비 중인 화면** |

Blogger의 애드센스 연동(수익 탭)이나 **자동 광고(Auto ads)** 를 켜면, 광고가
글 페이지뿐 아니라 **위 화면 전부에** 들어갑니다. 통지문이 말하는
"알림, 이동 또는 기타 행동 목적으로 사용되는 화면"이 정확히 이것들입니다.

여기에 첫 번째 위반이 겹칩니다. 라벨 페이지에는 글 요약만 뜨는데, 그 요약의
원본 글 자체가 얇았으므로 라벨 페이지는 **"가치가 낮은 콘텐츠를 포함한 화면"**
에도 해당합니다.

---

## 고치는 순서

### 1단계 — 자동 광고(Auto ads) 끄기 ⚠️ 가장 중요

자동 광고는 페이지 종류를 가리지 않고 광고를 넣습니다. 이 위반이 떠 있는
동안에는 **꺼 두는 것이 안전합니다.**

1. [애드센스](https://adsense.google.com) → **광고** → **사이트별**
2. `soo-c9.blogspot.com` 옆 **수정(연필)**
3. **자동 광고**를 **끄기**로 변경 → 사이트에 적용

승인된 뒤에 다시 켜도 됩니다. 지금은 통제 가능한 위치에만 광고를 두는 게
목적입니다.

### 2단계 — Blogger 광고 가젯을 글 페이지에만 노출

Blogger 레이아웃에 넣은 광고 가젯도 모든 화면에 나옵니다.

**방법 A — 가젯을 아예 빼기 (간단하고 확실함)**

Blogger 관리 화면 → **레이아웃** → 광고 가젯 → **삭제**

승인 전까지는 광고를 하나도 안 띄우는 게 가장 안전합니다. 애드센스 심사는
광고가 없어도 진행됩니다.

**방법 B — 테마에서 조건을 걸기 (광고를 유지하고 싶을 때)**

Blogger 관리 화면 → **테마** → **HTML 편집**.

광고 관련 위젯(보통 `<b:widget type='AdSense' ...>`)이나 애드센스 코드
조각을 찾아, 바깥을 아래 조건으로 감쌉니다.

```xml
<b:if cond='data:view.isSingleItem or data:view.isPage'>
  <!-- 여기에 기존 광고 코드 -->
</b:if>
```

- `data:view.isSingleItem` — 개별 **글** 페이지
- `data:view.isPage` — 고정 **페이지**(소개·문의 등)

이 두 경우에만 광고가 나오고, 라벨·검색·보관함·홈·404에서는 나오지 않습니다.

> ⚠️ **테마 HTML을 고치기 전에 반드시 백업하세요.**
> 테마 → 우측 상단 ▾ → **백업**. 테마 구조는 템플릿마다 달라서, 위 태그가
> 그대로 있지 않을 수 있습니다. 조건문 위치를 잘못 잡으면 블로그가 통째로
> 깨집니다. 자신이 없으면 **방법 A**를 쓰세요.

참고: [Blogger 레이아웃 데이터 태그](https://support.google.com/blogger/answer/47270)

### 3단계 — 404 페이지에 실제 내용 넣기

Blogger 관리 화면 → **설정** → **오류 및 리디렉션** → **맞춤 페이지 찾을 수 없음**

빈 오류 화면은 "콘텐츠가 없는 화면"입니다. 최소한 이 정도는 넣으세요.

```html
<p>찾으시는 글이 없습니다. 주소가 바뀌었거나 글이 내려갔을 수 있습니다.</p>
<p><a href="/">홈으로 가기</a> · <a href="/p/about.html">블로그 소개</a></p>
```

### 4단계 — 빈 페이지·빈 글 정리

Blogger 관리 화면 → **페이지** / **게시물** 에서 내용이 거의 없는 항목을
확인하고 **초안으로 되돌리거나 삭제**하세요. "아직 준비 중인 화면"에
해당합니다.

`Blogger Prune Posts` 워크플로가 얇은 **글**은 자동으로 걸러 주지만,
**페이지**는 직접 확인하셔야 합니다.

### 5단계 — 홈 화면에 전문 대신 요약 띄우기 (선택)

홈 화면에 여러 글의 전문이 그대로 나오면 중복 콘텐츠로 읽힐 수 있습니다.

Blogger 관리 화면 → **설정** → **게시물** → **더보기 링크 텍스트** 를 설정하면
목록에 요약만 나옵니다.

---

## 체크리스트

- [ ] 애드센스 → 광고 → 사이트별 → **자동 광고 끄기**
- [ ] Blogger 레이아웃 → 광고 가젯 **삭제**(방법 A) 또는 **조건 적용**(방법 B)
- [ ] 테마를 고쳤다면 **백업 먼저**
- [ ] 설정 → 오류 및 리디렉션 → **맞춤 404 페이지** 작성
- [ ] 빈 페이지·빈 글 초안 전환 또는 삭제
- [ ] 실제로 확인: 시크릿 창에서 `/search/label/재테크` 를 열어 **광고가 없는지**
- [ ] 실제로 확인: 없는 주소를 열어 404에 **내용이 있고 광고가 없는지**

마지막 두 항목은 눈으로 직접 보셔야 합니다. 설정만 바꾸고 확인하지 않으면
같은 사유로 다시 반려됩니다.
